# DNS加速第三方代理DNAT命中但不转发

## 结论

- 被测设备：`10.66.0.45`
- 客户端：`10.66.0.18` 的 `ens11 / 192.168.148.2`
- 模块：网络配置 -> DNS服务 -> DNS加速服务 -> 第三方代理
- 结果：第三方代理配置、运行状态和DNAT规则均正确，但客户端DNS请求命中DNAT后未进入conntrack，也未从WAN发出，客户端最终超时。
- 复现结果：多轮稳定复现。使用保留探针`192.0.2.53`和真实公网DNS探针`8.8.8.8`结果一致。
- 建议级别：高。该模式界面保存成功且规则显示已生效，但实际客户端无法解析DNS。

## 配置

第三方DNS按页面四个输入项配置：

```text
首选DNS:   180.76.76.76
备选DNS 1: 114.114.114.114
备选DNS 2: 223.5.5.5
备选DNS 3: 119.29.29.29
```

客户端将`8.8.8.8/32`固定经`192.168.148.1 dev ens11`进入被测设备，然后执行：

```bash
dig @8.8.8.8 www.baidu.com A +short +time=4 +tries=1 -b 192.168.148.2
```

## 期望结果

设备将目的DNS从`8.8.8.8:53`改写为活动第三方DNS`180.76.76.76:53`，经WAN发出；回包完成反向NAT并返回`192.168.148.2`，`dig`获得A记录。

## 实际结果

```text
communications error to 8.8.8.8#53: timed out
no servers could be reached
```

## 分层证据

| 层级 | 结果 | 证据 |
|---|---|---|
| L1 数据库 | 通过 | `enabled=yes`、`cachemode=2`，首选及3个备选DNS完整入库 |
| L2 运行态 | 通过 | `dnslink.status`存在，`proxy_ip=180.76.76.76`，第三方列表完整 |
| L3 NAT规则 | 通过 | DNSPROXY含`DNAT udp dpt:53 to:180.76.76.76:53` |
| LAN入口 | 通过 | `lan1`抓到`192.168.148.2 -> 8.8.8.8:53`的`www.baidu.com`查询 |
| DNAT命中 | 通过 | DNSPROXY DNAT包计数`0 -> 1` |
| conntrack | 失败 | 未找到`src=192.168.148.2`的UDP/53客户端条目 |
| 主备健康探测 | 通过 | `wan1`观察到首选及3个备选DNS的请求和响应 |
| WAN出口 | 失败 | LAN事务ID为`55726`，`wan1`无相同事务ID的`www.baidu.com`查询 |
| 客户端响应 | 失败 | `dig`超时 |

关键抓包：

```text
lan1:
192.168.148.2.51128 > 8.8.8.8.53: 55726+ A? www.baidu.com.

wan1:
观察到设备对四个第三方DNS的健康探测；个别轮次还观察到设备自身的
www.baidu.com查询，但其DNS事务ID与LAN请求不同，不能认定为客户端包。
自动化使用“域名+DNS事务ID”关联LAN/WAN同一请求。
```

DNAT规则及增量：

```text
before=0, after=1
DNAT udp -- !180.76.76.76 0.0.0.0/0 udp dpt:53 to:180.76.76.76:53
```

路由本身可用：

```text
180.76.76.76 via 10.66.0.1 dev wan1 src 10.66.0.45
```

同时，设备自身对`180.76.76.76`的健康探测有正常请求和响应，因此不是活动DNS不可达。

## 影响范围

同一轮自动化中以下功能均通过：

- UDP模式：L1/L2/L3、真实解析、强制REDIRECT、IPv4/IPv6/代理型反向代理、禁止AAAA、规则停启。
- DoH模式：请求地址入库、运行配置、直接解析、强制REDIRECT及计数。
- 多线分路模式：`port=0`、本地不监听53、经上游DNS真实解析、DNSPROXY入口计数增长。
- 第三方代理：仅真实客户端转发失败；配置、活动DNS选择、DNAT生成和规则命中均通过。

故障范围可收敛到第三方代理模式中“DNSPROXY DNAT命中后到客户端流conntrack/WAN转发前”的处理路径。
